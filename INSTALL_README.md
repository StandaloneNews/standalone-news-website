# Standalone News — Editorial + Markets Redesign

## Install in GitHub (Cloudflare static website)

1. Open: https://github.com/StandaloneNews/standalone-news-website
2. Click **Add file → Upload files**.
3. Upload exactly these files at the repository ROOT (not in an extra directory):
   - `index.html` (replace the old homepage)
   - `newsroom.css` (new)
   - `newsroom.js` (new)
4. Commit directly to `main`, then wait for the connected Cloudflare deployment to finish.
5. Open https://standalonenews.com/ and hard-refresh (`Ctrl+Shift+R`) if an older design is cached.

Keep these existing files and folders unchanged:
- `data/news.json` (your live headline feed)
- `data/articles.json` (your AI explainer listings)
- `scripts/`, `.github/workflows/` (your working RSS and Gemini automation)
- `articles/`, `styles.css` (previously generated standalone article pages)
- `assets/` (existing logo, icons and social image)

Old `news-app.css` and `news-app.js` may remain in the repository. They are not loaded by the new homepage.

## How the page works

- Headlines load dynamically from `data/news.json`. The code also checks optional `data/editorial.json` if present.
- AI-assisted explainers load from `data/articles.json` and link to the article files already generated by your publisher.
- Headlines link to the original publisher in another tab, not a copied article.
- The news wire can be searched and filtered; the list can be expanded.
- Save buttons and briefing preferences use the visitor's browser local storage. No login, server or cookie is required.
- Time displays use 24-hour UTC.
- Price widgets use TradingView-hosted embed components for tickers, indexes, popular stocks, futures, oil, gold, Treasury yields/futures, and bond ETFs. Exchange quote delays or data restrictions may apply. If the widgets are blocked, the page shows an explanatory fallback.
- The preview screenshots contain explicitly labeled example articles; the installed production homepage never inserts demonstration headlines.
- This is a homepage-only redesign. Previously generated article pages retain their existing design; no modifications were made to the publisher.

## Important

This package was browser-tested with locally mocked sample headlines. It was NOT deployed to your GitHub repository or tested against your live Cloudflare site, and it cannot guarantee TradingView data availability in each visitor's browser.

News images are original vector/abstract visual placeholders, not republished copyrighted photos. Licensed news photography can be integrated in a future update.
