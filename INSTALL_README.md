# Standalone News — Desktop-Bot-Style News Desk Upgrade

This update changes *what the public website highlights* and improves reading layout. It DOES NOT replace the local bot, upload its private database to a public repository, or change Gemini article generation.

## What changed

- The homepage lead story and Desk Picks are ranked automatically using timely, subject-based impact cues modeled on the desktop bot. Routine notices (e.g. old Fed meeting minutes) are downranked but remain available.
- Latest Headlines / News Wire remains chronological so readers can still find all articles.
- Publisher/agency summaries from direct RSS feeds appear as short, attributed excerpts. Google News discovery snippets are intentionally omitted since they frequently combine unrelated headlines. We do not generate unsupported summaries of other outlets' reporting.
- Topic variety and source diversity in the Desk Picks and 5-Story Brief.
- More readable typography and less oversized placeholder artwork on mobile.
- Technology category now works in topic selection and the News Wire.
- 24-hour UTC times, market widgets, SPY and QQQ, RSS feeds, saved items, and AI explainer links remain.

## Install precisely

1. In your GitHub repository `StandaloneNews/standalone-news-website`, replace these FOUR files in the repository root:
   - `index.html`
   - `newsroom.js`
   - `newsroom.css`
   - `markets-fix.js` (same market loader as your previous package; included for completeness)
2. Replace **`scripts/update_news.py`** with the same relative path from this ZIP. It must NOT be placed in the root of the repository.
3. Do not overwrite `data/news.json`, `data/articles.json`, `scripts/auto_publish.py`, `.github/workflows/*`, `articles/`, or any private desktop-bot database.
4. Commit to `main`. Go to GitHub Actions and manually run `Update public news feed` once so the RSS JSON includes new summary/desk_priority fields.
5. Wait for Cloudflare to deploy, then hard-refresh the site. The new homepage falls back to headline scoring even if the backend feed is not updated immediately.

## Reality check

- The website and Windows desktop bot are separate programs; this update aligns their ranking principles but does not upload the desktop bot's personally approved posts or local SQLite history.
- Desk selections are generated by a transparent keyword/recency heuristic; they are NOT verified or curated by human journalists.
- Direct publisher feeds may not provide a usable summary. In that case, visitors see the attributed headline and an external link, not an invented excerpt.
- The ranking algorithm is deliberately conservative and can be refined from visitor feedback and real examples.
- Website updates require a successful GitHub Actions feed refresh plus your normal deployment.
