ACCESS FOR EVERY READER

News should
be accessible.

We are working toward WCAG 2.2 Level AA accessibility across the Standalone News website. This page describes our approach; it is not a certification or guarantee of full legal compliance.

01 / FEATURES

Designed for varied needs

The website supports keyboard navigation, visible focus indicators, labeled search and topic filters, skip links, responsive layouts and reduced-motion preferences. Use your browser’s zoom or text settings to increase text size.

02 / TESTING

Automated sitewide checks

On November 23, 2026 (UTC), an automated WCAG 2.2 A/AA scan of 93 public HTML pages at mobile width and 16 key pages at desktop width reported no violations. The tests covered locally rendered content and excluded remote third-party scripts and iframes. This is a useful test result, not a certification of ADA compliance.

Periodic automated checks continue. Manual testing with screen readers, speech and keyboard navigation, zoom, and third-party market widgets is still necessary.

03 / LIMITATIONS

Ongoing evaluation

Automated checks cannot identify every accessibility barrier. We still need to validate the site with assistive technologies, keyboard-only use, different browsers and real user feedback. Content on linked external news sites is outside our control.

04 / FEEDBACK

Report an accessibility problem

If you encounter an accessibility barrier, contact Standalone News with the page URL and a description of the problem. You can also send feedback through @StandaloneNews on X (opens in a new tab). We use this feedback to prioritize improvements.
