ACCESS FOR EVERY READER

News should
be accessible.

We are working toward WCAG 2.2 Level AA accessibility across the Standalone News website. This page describes our approach; it is not a certification or guarantee of full legal compliance.

01 / FEATURES

Designed for varied needs

The website supports keyboard-accessible navigation, visible focus indicators, labeled search and topic filters, a skip link, responsive layouts and reduced-motion preferences. You can enlarge text using your browser settings or the Larger text control on the homepage.

02 / LIMITATIONS

Ongoing evaluation

Automated checks cannot identify every accessibility barrier. We still need to validate the site with assistive technologies, keyboard-only use, different browsers and real user feedback. Content on linked external news sites is outside our control.

03 / FEEDBACK

Report an accessibility problem

If you encounter a barrier, please contact us via @StandaloneNews on X (opens in a new tab) and describe the page and problem. We will use the feedback to prioritize improvements.
